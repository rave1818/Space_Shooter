# 게임 설명
탄막을 피하면서 보스를 공격해 점수를 획득하는 슈팅 탄막게임입니다.
* [게임 설명 영상](https://youtu.be/I6rEDm4YTDs)
# 개발 환경
* WinAPI C++ 사용
# 구현 기능
* 더블 버퍼링
* 플레이어 이동
* 오브젝트 풀링
* 보스 탄막
  * 부채꼴 탄막
  * 원형으로 줄어드는 패턴
  * 3개의 탄막이 원형으로 퍼지는 패턴
* 플레이어 스킬
  * 쉴드
* 버튼 구현
* UI
